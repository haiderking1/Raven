Raven configuration

Startup applications

raven.startup replaces the list of applications launched at session startup.

Contents
  • Configuration
  • Entry options
  • Disabling startup applications

Configuration

Lua
raven.startup {
    { "waybar" },
    { "awww-daemon" },
}

The default list contains Waybar. Saving changes does not start, restart, or stop these applications; the list runs once next session. A missing startup program does not stop the other entries.

Entry options

Lua
raven.startup {
    { "waybar" },
    {
        argv = { "foot", "--title", "Notes" },
        cwd = raven.env("HOME"),
        env = { EDITOR = "nvim" },
    },
}

Startup entry options
FieldDescription
argvExecutable followed by separate arguments. Required in the expanded form.
cwdWorking directory. Defaults to Raven’s working directory.
envEnvironment overrides for this application. Raven controls display routing.

Disabling startup applications

Lua
raven.startup {}
