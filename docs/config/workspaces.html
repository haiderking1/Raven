Raven configuration

Workspaces

raven.workspaces controls panel visibility hints. It does not change the ten-workspace count.

Contents
  • Configuration
  • Show all workspaces
  • Waybar

Configuration

Lua
raven.workspaces {
    show = "occupied",
    persistent = { 1, 2, 3, 4, 5 },
}

Workspace options
OptionDefaultDescription
show"occupied""occupied" shows occupied, active, and persistent workspaces. "all" shows all ten.
persistent{}Workspace numbers from 1 to 10 that remain visible when empty.

Show all workspaces

Lua
raven.workspaces { show = "all" }

Waybar

Use the ext/workspaces module with ignore-hidden set to true. With false, Waybar shows all ten regardless of Raven’s hints. Raven does not edit the Waybar configuration.
