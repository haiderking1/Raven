Raven configuration

Configuration

Raven reads ~/.config/raven/raven.lua. Changes apply when the file is saved.

Contents
  • Configuration file
  • Example
  • Configuration sections
  • Reloading

Configuration file

The file is created on first startup. If XDG_CONFIG_HOME is an absolute path, Raven uses $XDG_CONFIG_HOME/raven/raven.lua instead.

Example

Lua
raven.commands {
    terminal = { "foot" },
    launcher = { "rofi", "-show", "drun" },
}

raven.appearance {
    inner = 8,
    outer = 8,
    border = { width = 2 },
}

Edit the matching sections in your existing file. Omitted options use their defaults.

Reloading

Save the file or press Super+Shift+R. Invalid changes are rejected; the last working settings remain active. Startup applications are the exception: changes to their list take effect next session.
