Appearance

raven.appearance controls tiled-window gaps and window borders. Sizes use logical pixels.

Contents
  • Configuration
  • Per-axis and per-edge gaps
  • Resize animation
  • Window management
  • Taskbar restoration

Configuration

Lua
raven.appearance {
    inner = 8,
    outer = 8,
    border = {
        width = 2,
        active = "#228B22",
        inactive = "#355E3B",
    },
}

Appearance options
OptionDescription
innerGap between tiled windows. Default: 8.
outerGap around the tiling area. Default: 8.
border.widthBorder thickness. Default: 2. Use 0 to disable.
border.activeFocused-window border color.
border.inactiveUnfocused-window border color.

Gap and border widths accept whole numbers from 0 to 65535, constrained to fit the screen. Colors use #RRGGBB or #RRGGBBAA. Fullscreen windows have no gaps or border.

Per-axis and per-edge gaps

Lua
raven.appearance {
    inner = { horizontal = 8, vertical = 12 },
    outer = { top = 8, right = 12, bottom = 8, left = 12 },
}

Resize animation

Lua
raven.animations { resize_ms = 200 }

Animation options
OptionDefaultDescription
resize_ms200Duration in milliseconds, from 0 to 2000. Set 0 to disable the visual animation.

Normal windows have rounded corners with a fixed 16-logical-pixel radius, scaled with the output. Existing border colors and widths still apply. Fullscreen windows stay square; popup windows are not clipped to their parent’s corners. Traffic-light window buttons are not added.

Window management

The maximize action toggles between the layer-reserved workarea and the window’s previous tiled or floating placement. Client size limits still apply. The minimize action hides a window and its descendants while preserving their workspace and restore placement. Neither action has a default shortcut.

Lua
raven.bind("Super+M", "minimize")
raven.bind("Super+Shift+F", "maximize")

Taskbar restoration

Minimization requires a compatible taskbar or Dock using wlr foreign-toplevel-management. Waybar’s wlr/taskbar module provides this connection; clicking its entry with the activate action restores and focuses the window. Add wlr/taskbar to your existing module list rather than replacing unrelated modules.

JSON
{
    "modules-left": ["wlr/taskbar"],
    "wlr/taskbar": {
        "format": "{icon}",
        "on-click": "activate"
    }
}

Raven disables minimization when a window has no taskbar restore route. If that route disconnects, affected minimized windows become visible again. Alt+Tab does not automatically restore minimized windows. Traffic-light buttons, a native Dock, and minimize animations are not implemented yet.
