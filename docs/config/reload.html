Raven configuration

Reloading

Saving raven.lua reloads the configuration. Super+Shift+R requests a reload by default.

Contents
  • Application
  • Errors
  • Initial configuration

Application

Valid changes apply together after active window drags and resize/fullscreen transactions finish. Omitted options return to defaults. Startup applications are not relaunched.

Errors

An invalid reload leaves the working settings active. Fix the file and save again. The error window closes after a successful reload; Close or Escape dismisses it without changing settings. Copy error includes the report and technical details.

Initial configuration

If the initial configuration is invalid, Raven starts with built-in defaults and displays the error. Deleting the file during a session is an error, not a reset.
