Raven configuration

Cursor

raven.cursor selects an installed raster Xcursor theme and its size.

Contents
  • Configuration
  • Theme support

Configuration

Lua
raven.cursor {
    theme = "Adwaita",
    size = 24,
}

Cursor options
OptionDefaultDescription
theme"default"Installed Xcursor theme name. Theme inheritance and fallback apply.
size24Positive whole-number size in logical pixels.

Theme support

Theme and size reload together. If cursor preparation fails, the reload is rejected. SVG-only themes are not supported. Applications supplying their own cursor may render it differently.
