Keybindings

raven.bind assigns an action to a key combination. Reusing a combination replaces its binding.

Contents
  • Binding
  • Actions
  • Removing bindings
  • Defaults

Binding

Lua
raven.bind("Super+Return", "terminal")
raven.bind("Super+E", { spawn = { "nautilus", "--new-window" } })

Combine Super, Shift, Ctrl, and Alt with +. Key names include Return, space, F2, plus, and XF86AudioRaiseVolume. Use an unshifted key name with an explicit Shift modifier.

Actions

Binding actions
ActionArgumentEffect
terminal / launcherNoneRun the configured terminal or launcher.
closeNoneClose the focused window.
fullscreen / floatingNoneToggle the focused window’s mode.
quitNoneExit Raven.
reloadNoneReload the configuration.
workspace1 to 10Switch workspace.
move_to_workspace1 to 10Move the focused window.
vt1 to 12Switch virtual terminal.
{ spawn = { ... } }Executable and argumentsLaunch a command. Not preflight-checked on reload.
Lua
raven.bind("Super+2", "workspace", 2)
raven.bind("Super+Shift+2", "move_to_workspace", 2)
raven.bind("Ctrl+Alt+F2", "vt", 2)

Removing bindings

Lua
raven.unbind("Super+Q")

Other bindings remain unchanged. raven.clear_bindings() removes every configured binding, including quit and VT switching; add any required recovery bindings afterward.
