Screenshots

Print and Super+Shift+S open Raven's native area selector. No external screenshot program is required.

Taking a screenshot

  • Press Print or Super+Shift+S. The desktop freezes while you select an area.
  • Drag with the left mouse button, release it, then press Enter or Space to save and copy the selected area.
  • Press Enter or Space without dragging to capture the whole output.
  • Press Escape or right-click to cancel before confirmation.

The saved image excludes the cursor, selection border, and screenshot controls. Taking a screenshot does not change keyboard focus.

The selector opens with a dimmed desktop and a crosshair cursor, without a full-screen frame or hint panel. Dragging reveals a clear selected area. A thin outline sits outside its bounds, and the rest of the screen stays dimmed. The saved PNG has no dimming or outline.

Bindings

Lua
raven.bind("Print", "screenshot")
raven.bind("Super+Shift+S", "screenshot")

Both bindings are enabled by default. If you use raven.clear_bindings(), add them back explicitly. While the selector is open, Enter, Space, and Escape remain available even if bindings are reloaded.

Saved files and clipboard

PNG files go in Screenshots inside your XDG Pictures directory, normally ~/Pictures/Screenshots. Filenames contain the date, time, and a unique suffix. Existing files are not overwritten, and new screenshot files are private to your user.

The clipboard contains the image as image/png, not its filename. Paste it into an application that accepts images. Raven shows a confirmation when saving and copying finish. If saving fails after encoding, the image is still copied and the message explains the save failure.

Capturing the application switcher

While holding Alt+Tab open, press Print or Super+Shift+S. The frozen image includes the application switcher. Releasing Alt during capture does not activate the highlighted app.

Input and session changes

Finish an active window drag or close a popup or launcher that holds an input grab before opening the selector. Session suspension, workspace changes, output geometry changes, or a new input grab cancel an unfinished selection. Most other shortcuts are suppressed during selection; quit and VT-switch bindings still work.

Native capture only

This feature does not add a screencopy protocol, a screen-sharing portal, or permission for arbitrary Wayland clients to capture the screen.
