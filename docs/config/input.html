Raven configuration

Input

raven.input controls keyboard repeat and mouse acceleration. Save to apply changes.

Contents
  • Configuration
  • Keyboard repeat
  • Disable key repeat

  • Unsupported profiles

Configuration

Lua
raven.input {
    keyboard = {
        repeat_rate = 30,   -- repeats per second
        repeat_delay = 300, -- milliseconds
    },
    mouse = { accel_profile = "flat" },
}

Keyboard repeat

Keyboard options
OptionDefaultDescription
keyboard.repeat_rate25Repeats per second, from 0 to 1000. Use 0 to disable repeat.
keyboard.repeat_delay400Delay before repeating, from 0 to 60000 milliseconds.

Raven sends these values to applications. An application may implement its own repeat behavior. Changing repeat settings does not release held keys or change their shortcuts.

Disable key repeat

Lua
raven.input { keyboard = { repeat_rate = 0 } }

Mouse acceleration

Mouse acceleration profiles
mouse.accel_profileEffect
"default"Use each mouse’s libinput default. This is the default setting.
"flat"Disable speed-dependent acceleration. Movement still uses libinput’s constant device scaling.
"adaptive"Enable speed-dependent acceleration.

Applies to mice with configurable acceleration profiles, including mice connected later. Touchpads, pointing sticks, and devices without configurable profiles are left unchanged. This setting does not change pointer speed.

Lua
-- Disable mouse acceleration
raven.input { mouse = { accel_profile = "flat" } }

Lua
-- Enable mouse acceleration
raven.input { mouse = { accel_profile = "adaptive" } }

Lua
-- Restore each mouse’s default
raven.input { mouse = { accel_profile = "default" } }

Choose one profile and edit your existing raven.input block. Save to apply it; no session restart is needed.

Unsupported profiles

If a connected mouse cannot use the requested profile, Raven rejects the reload before applying the other settings. If a newly connected mouse cannot use the active profile, it keeps its existing profile and Raven logs the error.

Virtual pointers

Automation tools using wlr-virtual-pointer-unstable-v1 can send mouse clicks, movement, and scrolling. Launch them with a normal spawn keybinding. This does not provide virtual keyboard input.

Trusted tools only

Any client with access to Raven’s Wayland socket can use this protocol to control the pointer. There is no separate permission prompt.
