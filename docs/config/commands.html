Raven configuration

Terminal and launcher

raven.commands sets the programs used by the terminal and launcher actions.

Contents
  • Configuration
  • Arguments
  • Executable lookup

Configuration

Lua
raven.commands {
    terminal = { "foot" },
    launcher = { "rofi", "-show", "drun" },
}

Command options
OptionDefaultDescription
terminal{ "foot" }Terminal command. Bound to Super+Q by default.
launcher{ "fuzzel" }Launcher command. Bound to Super+D by default.

Arguments

Use one list entry per argument. Keep spaces within an argument in the same string.

Lua
raven.commands {
    terminal = { "foot", "--title", "My terminal" },
    launcher = { "rofi", "-show", "drun" },
}

Note

{ "rofi -show drun" } is a single executable name, not a command with arguments.

Executable lookup

Names are searched in Raven’s PATH. A name containing / is used as a path; relative paths start from Raven’s working directory. Shell aliases, ~, $HOME, and pipes are not expanded.

A missing or non-executable terminal or launcher rejects the reload. This check does not run the program or verify its arguments, dependencies, or wrapper commands.
