Troubleshooting

Common configuration errors and their fixes.

Command not found

Check spelling, installation, and Raven’s PATH. Shell aliases are not executable files. If foote was a typo for foot:

Lua
raven.commands { terminal = { "foot" } }

Command with arguments rejected

Arguments must be separate entries. Replace { "rofi -show drun" } with:

Lua
raven.commands { launcher = { "rofi", "-show", "drun" } }

Syntax error on a correct line

Check the preceding lines for missing commas, unmatched braces or quotes, and stray text. Lua can report where it detects the problem rather than where the mistake began. Raven may suggest an earlier line after checking a temporary correction; it never edits your file.

Lua
raven.appearance {
    border = {
        width = 2, -- comma required before the next entry
        active = "#228B22",
    },
}

Unknown setting

Setting names must match exactly. For example, use width rather than widht. The error lists the allowed names.

Program found but does not launch

Run the command in a terminal to inspect its error. It may have invalid arguments or missing dependencies. Raven’s executable check does not verify everything a program or wrapper does.

Startup application does not restart

Startup applications run once per session. Changes to their list apply next session.

Empty workspaces remain visible

Set ignore-hidden to true in Waybar’s ext/workspaces module to honor Raven’s visibility hints.
