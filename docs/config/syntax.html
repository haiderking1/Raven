Raven configuration

Basic syntax

Settings are written as calls to raven.* functions.

Contents
  • Example
  • Commands with arguments

Example

Lua
-- Terminal and launcher
raven.commands {
    terminal = { "foot" },
    launcher = { "rofi", "-show", "drun" },
}

Quote text, separate entries with commas, and keep matching braces. Lines beginning with -- are comments.

Commands with arguments

Lua
raven.commands { launcher = { "rofi", "-show", "drun" } }

The first entry is the executable. Each following entry is one argument. No shell splitting or expansion is performed.
